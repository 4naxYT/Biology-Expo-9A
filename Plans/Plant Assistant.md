# Idea:
## Naming Scheme:
- [ Difficult ] : Requires A Lot More Work
- [ Mvp ] : Main Feature

## Steps:
- User Plugs <x> into a plant
- User Inputs Type/Species of plants
- User Inputs A photo of the plant's Affected leaves [Difficult] 
- We Fetch Info:
  - Optimal Temps
  - Optimal Humidity
  - Preferred pH Level
  - Optimal Lighting Conditions
  - Carnivorous ? (Y/N)
  - Aquatic ? (Y/N)
    - Water Temps
    - Amonia Lev
  - Manual Pollination Preferred? (Y/N)
  - Watering Frequency
  - Common Pests
- It Calculates Most Probable Issues
- It calculates Most probable Fixes
- It outputs confidence, issues, fixes [MVP]

## Aync Features:
- Loging current pogress for things that require time to calculate
- Matplotlib for graphing Values
